This website shows my research wall. The wall is an Excalidraw drawing that lives in my Obsidian vault, not in this project. The file `source.md` is a link to that drawing, so changes I make in Obsidian show up here too.

To look at it, run this command in the project folder:

```
python3 -m http.server
```

Then open http://localhost:8000 in a browser.
